# Pip's Cozy Dream Workshop

🌐 **Live Demo:** [https://ha-x-baby-web-hackathon-pip-s-cozy.vercel.app/](https://ha-x-baby-web-hackathon-pip-s-cozy.vercel.app/)

A whimsical, interactive bedtime story experience built for **HaX.baby — Baby's First Website Hackathon**.


## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
